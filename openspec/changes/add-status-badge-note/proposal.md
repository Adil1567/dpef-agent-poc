## Why

There's no single file summarizing which efforts in this repo are active vs. archived, which makes it hard for a new contributor to know what `research_chat_agent` and `dpef-agent` actually are without digging through `openspec/`.

## What Changes

- Add a `STATUS.md` file at the repo root listing each effort (research_chat_agent, dpef-agent) with a one-line description and its current status (active/experimental).

## Capabilities

### New Capabilities
- `project-status`: a status file summarizing the repo's active efforts.

### Modified Capabilities
(none)

## Impact

- Affects: repo root only (`STATUS.md`), no changes to research_chat_agent or dpef-agent code.
